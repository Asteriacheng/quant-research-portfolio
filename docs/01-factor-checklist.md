# 单因子研究检查清单 / Factor Research Checklist

> **EN abstract** — A fixed five-gate pipeline for validating a single cross-sectional factor
> (effectiveness → turnover → cost → decay → correlation with the existing pool), the numeric
> thresholds I use for daily A-share data, and where each check is implemented in `factorkit`.
> The point of the list is not to find factors; it is to **kill** them cheaply and in a fixed order.

判一个因子研究流程靠不靠谱,看它**拒绝**因子的流程,不看它产生因子的流程。
下面五关顺序固定,前一关不过后面全免——不是为了严格,是为了省算力:
最便宜的检验放最前面。

---

## 第 0 步 · 先把「信号」和「因子」分清

| 类型 | 形态 | 走哪条路 |
|---|---|---|
| **连续截面因子** | 每天每只股票一个数值,可排序 | IC 流程(本文主线) |
| **布尔选股信号** | 稀疏事件,触发/不触发 | 事件研究 + 机械基线(见 [03](03-backtest-integrity.md) 与 `factorkit.event_study`) |

一条常犯的错:把通达信那种「11 个条件 AND 起来」的指标整体拿去测 IC。
条件越多样本越少、过拟合越重,而且**分不清是谁在贡献**。
正确做法是**拆出连续中间变量当因子测**;确实要测整条 AND 链,就必须配 drop-one 消融。

---

## 第 1 步 · 有效性(无效则后面全免)

| 指标 | 定义 | 经验判读(A 股日频) |
|---|---|---|
| RankIC | 因子值与前向收益的日度截面 Spearman | \|IC\| > 0.02 可用;> 0.05 很强 |
| ICIR | mean(IC) / std(IC) | > 0.3 尚可;> 0.5 稳定 |
| t 值 | mean/std × √天数 | 多重检验环境下 \|t\| > 3 才算站住,2 不够 |
| 分组单调性 | 按因子分 10 组,组间收益应单调 | 只有两头有、中间乱 = 尾部效应,不是线性 alpha |
| 方向稳定性 | 前半段 IC 与后半段 IC 同号 | 不同号直接判死,别做「分段解释」 |

两条纪律:

1. **方向以实测为准,不信指标的名字和故事。** 卖方指标的「庄家/散户」叙事与截面
   实测方向可以完全相反——见 [02 案例](02-case-tdx-indicator-teardown.md)。
2. **前向收益要用可执行口径。** T 日收盘出信号 → T+1 开盘买入 → T+1+H 开盘卖出。
   用 T 日收盘价当买入价,回测赚的是一个不存在的成交机会。

实现:`factorkit.rank_ic` / `ic_summary` / `quantile_stats` / `forward_return(mode="open_to_open")`

---

## 第 2 步 · 换手率

- 门槛:top10% 组合**日**换手 < 0.3 较舒服,> 0.6 必须处理。
- 手法:`ts_mean(x, d)` / `decay_linear(x, d)` 平滑。
- **平滑是拿 IC 换 turnover**:窗口越长换手越低、信号越钝。扫窗口 {3,5,10,20}
  画 IC–turnover 曲线找拐点,不是无脑加窗口。
- 秩自相关是换手的镜像读数:> 0.95 慢因子,< 0.5 快因子。

实现:`factorkit.top_turnover` / `factor_autocorr`

---

## 第 3 步 · 交易成本

粗算:**年化成本 ≈ 日换手 × 年交易日 × 双边费率**。

以单边 7.5bp + 滑点 5bp(双边 25bp)为例:日频满换手 ≈ 年 244 次 → 成本 ≈ 61%/年,
什么 alpha 都喂不起。

这一步的价值不在精确,在于**建模之前就把喂不起的因子劝退**。
after-cost 期望 ≤ 0 的因子只能当组合里的调味料(降相关/择时),不能单独扛仓位。

实现:`factorkit.annual_cost_drag`

---

## 第 4 步 · Alpha 衰减

做法:factor(T0) 分别对 **t+k 单日收益**(k = 1,2,3,5,10)算 IC,画衰减曲线。
用累计收益画衰减会被前几天的强信号糊住,必须用单日收益。

读法:

- 衰减慢(t+10 仍有 60% 强度)→ 容量大、宜实盘、可配长持有;
- 衰减快(t+3 归零)→ 必须快执行、对滑点极敏感、只配短持有;
- **快因子 + 高换手 + 成本 = 三杀**,基本判死。

实现:`factorkit.decay_curve`

---

## 第 5 步 · 与池内相关性

- 口径:与池内**每一个**已有因子算日度截面秩相关。
- 门槛:|corr| < 0.7 才谈得上入池,< 0.3 才算真新鲜。
- 降相关手段:
  1. **残差化/正交化**(治本):新因子对旧因子做截面回归取残差,残差还有 IC 才算带来新钱;
  2. 换数据源/换构造逻辑(治标):同一个想法换个写法,往往还是 0.8+ 相关。
- 陷阱:**同一条公式里拆出来的多个变量,常常是同一信息源的不同写法**。
  实测过一个例子:一条指标拆出的 4 个变量互相 |corr| 0.81~0.95,最后只能留一个。

判的是「赚的是不是同一笔钱」,不是「表达式长得像不像」。

实现:`factorkit.correlation_with_pool` / `residualize`

**五关全过 → 入池登记。** 入池不是终点,是进入组合层的入场券。

---

## 组合层:合成预期收益 μ

先立靶子再谈模型:

| 基准 | 做法 | 备注 |
|---|---|---|
| **等权 1/N** | 标准化后等权相加 | 出名地难打败(DeMiguel 1/N),必须先跑它 |
| IC 加权 | 滚动 mean(IC) 做权重 | 略强的 naive 基准 |
| ICIR 加权 | 滚动 mean(IC)/std(IC) | 同上,压波动 |

**模型跑不赢等权 → 不上模型。** 这句话我有数字背书:曾经把 7 个通过检验的因子
分别喂给等权 / ICIR 加权 / LightGBM,结果是复杂度单调递减收益(等权 > ICIR > LGBM)
——7 个特征喂树模型就是在拟合噪声。

其他两条:

- 线性合成必须加正则(Ridge/Lasso)或先正交化,因子共线时纯 OLS 权重极不稳定;
- 非线性首选树模型(XGBoost/LightGBM),训练一律**时间 walk-forward,禁止随机切分**
  ——时间序列随机切分等于偷看未来。

## 组合构建层:μ + 风险模型 → 权重

```
max  wᵀμ − λ·wᵀΣw
s.t. 行业中性 / 风格暴露上限 / 个股权重上限 / 换手约束 / 多头 w ≥ 0
```

- Σ 用 Barra 式结构化风险模型估计(行业+风格因子协方差 + 特质对角项);
  样本协方差在 股票数 > 样本期 时不可逆、噪声大,不可用。
- **alpha 模型只负责预测 μ,不直接输出持仓权重**。换 alpha 模型不用动优化器,
  加风控约束不用重训模型——这就是预测层与优化层解耦的价值。
- 波动率/回撤目标在这一层实现,**不要**倒回去改 alpha 模型。

---

## 一句话总结

因子研究的产出不是「我挖到了一个因子」,而是**「这口井有多深」的可信测量**。
一个能诚实告诉你「这里没有矿」的流程,比一个总能挖到矿的流程值钱得多。
